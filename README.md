# St. Luke's Medical Center Hospital Management System using Spring Boot 3 & Spring Security 6

**A cloud-based hospital management solution built with modern web technologies.**

## Overview
This project is an implementation of a RESTful API for managing healthcare platform where you can browse doctors, manage profiles, and book appointments. .

**Key Features:**
* Creating and managing clients
* Update, Delete and retrieving a particular clients by id
* Retrieving a list of all clients
* Creating and managing insurance policies for clients
* Update, Delete and retrieving a particular insurance policies by id
* Retrieving a list of all insurance policies
* Creating and managing claim for insurance policies
* Update, Delete and retrieving a particular claim by id
* Retrieving a list of all claim
* Retrieving a list of all claim for a client
* Authenticating users and generating JWT tokens for authorization

### Tech Stack:

* **Frontend:** React, Vite, Tailwind CSS
* **Database:** Postgres
* **Backend:**  Spring Boot Web, Spring Data JPA, Lombok, Spring Security 6, JWT (Json Web Token), Maven
* **Testing:**  JUnit, Mockito,
* **Deployment:** Docker, Github Actions, Netlify, Render, AWS Elastic Beanstalk, S3 & RDS Postgres
